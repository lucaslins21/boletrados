# Boletrados ⚽🏆

Quiz de futebol para disputar um X1 por turnos com amigos. Protótipo inicial em React e TypeScript.

Regras: 6 categorias, sorteio de bolinhas antes de cada pergunta normal, 15 segundos para responder, 3 acertos consecutivos liberam tentativa de troféu, mantém a vez após acerto, erro passa a vez. Vence quem completar os 6 troféus.

**Status:** demonstração local; autenticação, convites reais e backend ainda não foram implementados.

Consulte `docs/PRODUCT.md` e `docs/CLAUDE_HANDOFF.md`.
